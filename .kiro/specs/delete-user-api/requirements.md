# 要件定義書

## 概要

本ドキュメントは、アカウント削除API `DELETE /api/v1/users/{userId}` の要件を定義する。このAPIは、ユーザーが自分のアカウントを削除するための機能を提供する。

## 要件

### 要件 1: ユーザーアカウント削除の基本機能

**目的:** 認証済みユーザーとして、自分のアカウントを削除したい。なぜなら、サービスの利用を停止し、データを完全に削除したいからだ。

#### 受け入れ基準

1. When ユーザーが `DELETE /api/v1/users/{userId}` にリクエストを送信する, the User API shall ユーザーIDに対応するアカウントを削除する
2. When アカウント削除が成功する, the User API shall 204 No Content ステータスを返す
3. When ユーザーが存在しない, the User API shall 404 Not Found エラーを返す
4. The User API shall 削除されたユーザーのJWTトークンを無効化する

### 要件 2: パスワード確認

**目的:** ユーザーとして、アカウント削除前にパスワード確認を行いたい。なぜなら、誤操作や不正な削除を防ぐためだ。

#### 受け入れ基準

1. When ユーザーがアカウント削除リクエストを送信する, the User API shall リクエストボディに`password`フィールドを要求する
2. When パスワードが正しくない, the User API shall 400 Bad Request エラーを返す
3. When パスワードが指定されていない, the User API shall 400 Bad Request エラーを返す

### 要件 3: 認証・認可

**目的:** 認証済みユーザーとして、自分のアカウントのみ削除したい。なぜなら、他のユーザーのアカウントを不正に削除されるのを防ぐためだ。

#### 受け入れ基準

1. When リクエストに有効なJWTトークンが含まれない, the User API shall 401 Unauthorized エラーを返す
2. When JWTトークンのユーザーIDと削除対象のユーザーIDが一致しない, the User API shall 403 Forbidden エラーを返す
3. While ユーザーが認証済み, the User API shall 自分のアカウントのみ削除を許可する

### 要件 4: 関連データの削除

**目的:** ユーザーとして、アカウント削除時にすべての関連データも削除されたい。なぜなら、データの完全削除を保証したいからだ。

#### 受け入れ基準

1. When ユーザーアカウントが削除される, the User API shall そのユーザーのすべてのサブスクリプションを削除する
2. When ユーザーアカウントが削除される, the User API shall そのユーザーのすべてのラベルを削除する
3. When ユーザーアカウントが削除される, the User API shall そのユーザーのすべての支払い履歴を削除する
4. The User API shall データベースの外部キー制約とカスケード削除設定に従って関連データを削除する

### 要件 5: エラーハンドリング

**目的:** ユーザーとして、削除処理の失敗時に適切なエラーメッセージを受け取りたい。なぜなら、何が起きたかを理解したいからだ。

#### 受け入れ基準

1. If データベースエラーが発生する, then the User API shall 500 Internal Server Error を返し、エラーをログに記録する
2. If 予期しない例外が発生する, then the User API shall 汎用的なエラーメッセージを返し、詳細をログに記録する
3. The User API shall 既存の共通エラーハンドラ(`app/common/error_handlers.py`)を使用してエラーレスポンスを整形する

### 要件 6: 監査ログ

**目的:** システム管理者として、アカウント削除操作を追跡したい。なぜなら、セキュリティ監査や問題調査のためだ。

#### 受け入れ基準

1. When ユーザーアカウントが削除される, the User API shall 削除操作をログに記録する（ユーザーID、タイムスタンプ）
2. When アカウント削除が失敗する, the User API shall 失敗の詳細をログに記録する
