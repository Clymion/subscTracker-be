# 実装タスク

## TDDアプローチ

本タスクはt-wadaのTDD（テスト駆動開発）アプローチに従って実装を進める。

**サイクル**: Red → Green → Refactor
1. **Red**: まず失敗するテストを書く
2. **Green**: テストを通すための最小限のコードを書く
3. **Refactor**: コードを整理・改善する
