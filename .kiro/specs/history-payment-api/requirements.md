# 要求仕様書

## 概要
本ドキュメントは、支払履歴API機能の要求仕様を定義します。この機能により、ユーザーは自身のサブスクリプションに対する支払履歴を取得し、支出を明確に把握できるようになります。

## 要求事項

### 要求事項1：支払履歴の取得
**目的：** ユーザーとして、自身の支払履歴を取得したい。これにより、サブスクリプションの支出を追跡できるようにする。

#### 受け入れ基準
1. WHEN ユーザーが支払履歴を要求した場合、THEN システムはユーザーの支払リストを返却しなければならない。
2. IF ユーザーに支払履歴が存在しない場合、THEN システムは空のリストを返却しなければならない。
3. WHEN ユーザーが支払履歴を要求した場合、THEN リスト内の各支払情報には、支払日、金額、通貨、およびサブスクリプション名が含まれなければならない。
4. IF 支払が削除済みのサブスクリプションに関連付けられている場合、THEN システムは最後に認識されていたサブスクリプション名と共にその支払情報を履歴に含めなければならない。

### 要求事項2：フィルタリングとページネーション
**目的：** ユーザーとして、支払履歴をフィルタリングおよびページ分割したい。これにより、特定の支払情報を簡単に見つけられるようにする。

#### 受け入れ基準
1. WHEN ユーザーが特定のサブスクリプションを指定して支払履歴を要求した場合、THEN システムはそのサブスクリプションの支払情報のみを返却しなければならない。
2. WHEN ユーザーが日付範囲を指定して支払履歴を要求した場合、THEN システムはその日付範囲内の支払情報のみを返却しなければならない。
3. WHEN ユーザーが支払履歴の特定のページを要求した場合、THEN システムはページ分割された支払リストを返却しなければならない。
4. IF ユーザーが存在しないページ番号を要求した場合、THEN システムは空の支払リストを返却しなければならない。
