# 要求仕様書

## 概要
本ドキュメントは、為替レート取得API (`/api/v1/exchange-rates`) の修正に関する要求を定義します。
この修正により、ユーザーはOpenAPI仕様書に準拠した形で、特定の日付や通貨に基づいた為替レート情報を柔軟に取得できるようになります。

## 要求事項

### 要求1: 為替レート取得APIの動作仕様
**目的:** ユーザーとして、指定した条件（日付、基準通貨、対象通貨）で為替レートを取得したい。これにより、正確な通貨換算が可能になる。

#### 受入基準
1.  `WHEN` 認証済みのユーザーが `/api/v1/exchange-rates` にGETリクエストを送信した場合, `THEN` システムは最新の為替レート情報を返却しなければならない。
2.  `WHEN` ユーザーが `date` パラメータを指定してリクエストを送信した場合, `THEN` システムは指定された日付の為替レート情報を返却しなければならない。
3.  `WHEN` ユーザーが `base_currency` パラメータを指定してリクエストを送信した場合, `THEN` システムは指定された通貨を基準とした為替レート情報を返却しなければならない。
4.  `WHEN` ユーザーが `target_currencies` パラメータを指定してリクエストを送信した場合, `THEN` システムは指定された対象通貨の為替レート情報のみを返却しなければならない。
5.  `IF` `date` パラメータが不正なフォーマット（YYYY-MM-DD以外）の場合, `THEN` システムはステータスコード `400 Bad Request` を返却しなければならない。
6.  `IF` `base_currency` または `target_currencies` パラメータに不正な通貨コードが含まれている場合, `THEN` システムはステータスコード `400 Bad Request` を返却しなければならない。
7.  `IF` 指定された条件に該当する為替レートデータが存在しない場合, `THEN` システムはステータスコード `404 Not Found` を返却しなければならない。
8.  `IF` リクエストに有効な認証トークンが含まれていない場合, `THEN` システムはステータスコード `401 Unauthorized` を返却しなければならない。
9.  `IF` リクエストが成功した場合, `THEN` システムは `date`, `base_currency`, `rates` を含むJSONオブジェクトを返却しなければならない。
